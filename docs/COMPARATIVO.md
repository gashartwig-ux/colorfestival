# Web actual vs. Color Festival 2.0

| Área | Web actual | Color Festival 2.0 |
| --- | --- | --- |
| Jerarquía | Varias secciones visualmente similares | Recorrido priorizado: impacto, edición, experiencia, entradas |
| Hero | Mensaje y CTA básicos | Portada cinematográfica con secuencia real, ubicación y dos acciones claras |
| Entradas | Botón sin destino confirmado | Módulo reutilizable con estado, fecha, lotes y enlace editable |
| Experiencia | Historia extensa | Música, sunset, amigos, color y verano con impacto visual |
| Video | Reproductor convencional | Aftermovie inmersivo con modal y acceso a otras ediciones |
| Galería | Tira de imágenes y Drive | Galería integrada, filtros por edición y lightbox |
| Ubicación | Mapa y texto aislados | Mapa, datos prácticos, CTA y evento de medición |
| Mobile | Adaptación básica | Navegación, tipografía, galería y carruseles priorizados para redes |
| Conversión | Sin recorrido medible claro | Eventos para entradas, video, WhatsApp, Instagram, ubicación y navegación |
| Calidad técnica | Estructura inicial | Metadatos, Open Graph, robots, sitemap, carga diferida y datos de evento condicionales |

La web pública original no fue modificada.
