# Color Festival 2.0

Nueva experiencia digital de Color Festival, construida de forma independiente para no modificar la web pública actual hasta su aprobación.

## Ejecutar el proyecto

Requisitos: Node.js 22.13 o superior y npm.

```bash
npm install
npm run dev
```

Para validar la versión de producción:

```bash
npm run build
```

## Edición rápida

La fecha, estado de entradas, enlaces, videos y fotografías se administran desde:

`app/festival-config.ts`

La guía completa está en `docs/EDICION-Y-CONTENIDO.md`.

## Medición

Los eventos comerciales están preparados, pero Google Analytics 4 y Meta Pixel permanecen inactivos hasta recibir identificadores reales. Ver `docs/MEDICION.md`.

## Información pendiente

- Fecha y horario de la próxima edición.
- Enlace y estado real de entradas.
- Lotes y precios.
- Edad mínima.
- Política climática.
- Objetos permitidos y estacionamiento.
- Identificadores de analítica y publicidad.

No se inventaron fechas, precios, artistas ni estadísticas.
